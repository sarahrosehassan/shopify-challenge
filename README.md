How to run the web application

Python and Flask framework are used in this application.

1. Download Python 3.7.4:
https://www.python.org/downloads/release/python-374/

2. Open the command line in "...Python\Python37-32\Scripts" and run a command, where 'requirements.txt' should be a path to the requirements.txt file in the project folder:
pip install -r requirements.txt

3. Open the command line in your python directory, then move to the project folder and run a command:
python main.py

4. Open the following address in your web browser:
http://localhost:5000
